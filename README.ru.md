[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md) | **Русский** | [Español](README.es.md)

Кроссплатформенный лаунчер Minecraft (Java / Bedrock Edition) на Qt и C++ с активным использованием ИИ. Одна коробка — целый мир блоков.

## Возможности

- **Управление сборками**: создание, импорт, переключение между версиями и запуск сборок Java / Bedrock, миграция из других лаунчеров
- **Загрузка контента**: моды, модпаки, наборы ресурсов и шейдеры — из CurseForge и Modrinth
- **ИИ-помощник**: чат с ИИ, умная диагностика логов падения, помощник по командам (естественный язык → команды игры)
- **Система плагинов**: встроенные SDK плагинов и менеджер плагинов, поддержка локальных расширений (см. `sdk/`)
- **Редактор скинов**: встроенный редактор с 3D-предпросмотром
- **Игра по сети**: передача миров по локальной сети, туннельное подключение
- **Управление сохранениями**: резервное копирование и восстановление миров
- **Многоязычность**: китайский (упрощённый), китайский (традиционный), английский, испанский, японский, русский

## Поддерживаемые платформы

- Windows
- macOS
- Linux
- HarmonyOS
- Android

## Технологии

- **Фреймворк**: Qt 5.15+ / Qt 6.x
- **Язык**: C++
- **Интерфейс**: Qt Widgets + темы QSS
- **Сборка**: qmake

## Сборка

### Windows

1. Установите Qt Creator и компилятор MinGW (или MSVC)
2. Откройте Qt Creator и импортируйте `BlockBox.pro`
3. Выберите 64-битный комплект, соберите и запустите

### macOS

1. Установите Qt Creator и Xcode
2. Импортируйте `BlockBox.pro` и выберите комплект Clang 64-bit
3. Соберите и запустите

### Linux

```bash
sudo apt-get install qtbase5-dev qt5-qmake build-essential
qmake BlockBox.pro
make
./BlockBox
```

### HarmonyOS

Установите среду разработки HarmonyOS и плагин Qt for HarmonyOS, затем выберите комплект HarmonyOS в Qt Creator для сборки и развёртывания.

## Настройка ключей API

В этом репозитории **нет сторонних ключей API**. Все учётные данные настраиваются локально и никогда не отправляются вместе с кодом:

- **Вход в аккаунт Microsoft**: `client_id` в `utils/AuthManager.cpp` — это заглушка, укажите своё значение локально. **Не коммитьте настоящие ключи в репозиторий** (настроена проверка pre-push, которая их блокирует)

## Адаптация под платформы

Различия между платформами обрабатываются условной компиляцией: макросы `WINDOWS_OS` / `MAC_OS` / `LINUX_OS` / `HARMONY_OS`. Реализация находится в `platform.cpp` и `platform.h` и охватывает каталог данных приложения, пути конфигурации и определение платформы.
